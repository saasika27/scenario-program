# SOFTWARE REQUIREMENTS SPECIFICATION (SRS)

## Project Title
ExamInsight – Online Examination Management System

 1. Introduction

 1.1 Purpose
The purpose of ExamInsight is to develop a Java-based Online Examination Management System that simplifies examination activities, automatic evaluation, result generation and student performance monitoring.

 1.2 Scope
The system provides separate login facilities for Students and Faculty.

Students can:
- Log in to the system.
- View available examinations.
- Attend registered MCQ examinations.
- View examination results.
- View performance details.

Faculty can:
- Log in to the system.
- View all examinations.
- Add new MCQ questions.
- View student examination results.
- View student performance.

1.3 Intended Users
- Students
- Faculty Members

 2. Overall Description

 2.1 Product Perspective
ExamInsight is a standalone Java console-based application connected to a MySQL database using JDBC.

 2.2 Product Functions
- Student authentication
- Faculty authentication
- Examination listing
- MCQ question management
- Examination participation
- Automatic answer evaluation
- Result generation
- Performance monitoring

 2.3 User Characteristics
Users should have basic computer knowledge and valid login details to access the system.

 3. Functional Requirements

FR-01: Student Login
The system shall allow students to log in using their Student ID.

FR-02: Faculty Login
The system shall allow faculty members to log in using their Faculty ID and password.

FR-03: View Examinations
The system shall display available examinations to students.

FR-04: Add Questions
The system shall allow faculty members to add MCQ questions with four options, correct answers and marks.

FR-05: Attend Examination
The system shall allow students to attend examinations for which they are registered.

FR-06: Automatic Evaluation
The system shall evaluate submitted answers and calculate marks automatically.

FR-07: Result Generation
The system shall generate total marks, percentage, grade and pass/fail status.

FR-08: View Results
The system shall allow students and faculty to view examination results.

FR-09: Performance Analysis
The system shall display student performance information.

FR-10: Logout
The system shall allow users to return to the main menu.

 4. Non-Functional Requirements

 4.1 Performance
The system should retrieve and store examination information efficiently.

 4.2 Reliability
The system should maintain examination and result records in the MySQL database.

 4.3 Usability
The application should provide a simple menu-driven console interface.

 4.4 Security
The system should restrict faculty functions through faculty login authentication. Database credentials should be configured securely.

 4.5 Maintainability
The Java source code should be organized into separate classes for easier maintenance.

 5. Hardware Requirements
- Computer or Laptop
- Minimum 4 GB RAM
- Keyboard and Monitor
- Sufficient storage space

 6. Software Requirements
- Operating System: Windows / Linux
- Programming Language: Java
- JDK
- Database: MySQL
- Database Connectivity: JDBC
- MySQL Connector/J
- MySQL Workbench (recommended)
- Java-supported IDE or Command Prompt

 7. Database Requirements

Database Name: ExamInsightDB

The system uses seven tables:
1. Student
2. Faculty
3. Examination
4. Question
5. Registration
6. Student_Response
7. Result

 8. Constraints and Assumptions
- MySQL Server must be running.
- The database must be created before executing the application.
- Users must have valid login details.
- Students can attend examinations for which they are registered.
- The current application supports MCQ-based examinations.

 9. Expected Outcome

The system aims to simplify examination management through automated MCQ evaluation, result generation and student performance monitoring using Java, JDBC and MySQL.

 10. Conclusion

ExamInsight provides a simple and organized examination management solution with separate Student and Faculty modules. It reduces manual evaluation effort and stores examination records in a centralized MySQL database.
